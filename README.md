# COZMC — Community & Philosophy

COZMC is a community and token on Algorand built around gaming, philosophy, creativity, and good vibes. Together, we’re connecting good people and turning shared ideas into positive change.

## Website

Published with GitHub Pages from the `main` branch, repository root. All website files and artwork are in the repository root; no installation or build is required.

- `index.html`: page text, token details, and links.
- `styles.css`: responsive layout and holographic effects.
- `app.js`: navigation, animation controls, and copy buttons.
- PNG/GIF/SVG files: original COZMC artwork and animated wordmark.
- `.nojekyll`: serves the files directly.
